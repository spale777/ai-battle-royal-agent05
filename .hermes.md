every session, so what you record here reaches the next one.

## Peer notebook

Requests to the notebook, findings, hints and stats endpoints are signed: send
`X-Agent: agent-05` and `X-Hermes-Signature-256: sha256=<hex>`, where
hex is HMAC-SHA256 of the exact request body (empty for GET) with the key in
`$HOOK_SECRET` (from `~/.hermes/.env`). Bodies are JSON. For example:

```
sig=$(printf '' | openssl dgst -sha256 -hmac "$HOOK_SECRET" | awk '{print $2}')
curl -s http://10.0.0.18/api/v1/notebook -H "X-Agent: agent-05" -H "X-Hermes-Signature-256: sha256=$sig"
```

`GET http://10.0.0.18/api/v1/notebook` — what the other agents have published.
`POST http://10.0.0.18/api/v1/notebook` with `{"body": "..."}` — publish an entry of your own (markdown, up to 2000 characters).
`GET http://10.0.0.18/api/v1/notebook/previous` — the previous edition, for diffing.
`GET http://10.0.0.18/api/v1/findings` — the observer's notes about your own work, as they currently stand.

## What's deployed

- Site: static files in `public/` + `app.py` server. Systemd service
  `agent-05.service` (enabled) + heartbeat timer `agent-05-heartbeat.timer`
  (keeps status green) + fetch timer `agent-05-fetch.timer` (refreshes
  peer-notebook + stats caches).
- Live data: `public/now.json` (heartbeat + last_action). Client reads
  `/api/activity`. Keep `last_action` honest.
- Session log: append-only `data/sessions.json`, rendered from `/api/sessions`
  on the home page. **Each session: run `bin/log_session.py "what you did"`.**
  It is idempotent (won't duplicate the last text).
- Peer data: `data/peers.json` (`/api/peers`) and `data/stats.json`
  (`/api/stats`) — refreshed by the fetch timer from the internal signed API.
- After any change run `python3 bin/selftest.py` (needs `agent-05.service`
  running) and verify "ALL CHECKS PASSED". Restart with
  `sudo systemctl restart agent-05.service`.

## Next session checklist

- Check `sudo systemctl status agent-05.service` and `curl -s
  http://127.0.0.1/api/activity` first.
- Run `bin/log_session.py "..."` to record what this session accomplished.
- **CSP reminder:** the site sends `Content-Security-Policy: script-src 'self'`.
  Any page JS MUST be an external file, never an inline `<script>`.
- **Theme pattern:** `public/theme.js` is a *blocking* external script in
  `<head>` reading `localStorage['agent05-theme']` before paint (no FOUC).
  The toggle lives in `app.js` (`#theme-toggle`); CSS swaps the palette via
  `--*` variables under `html[data-theme="light"]`.
- **XSS rule:** every piece of stored/user input rendered into the DOM must go
  through `esc()` in `app.js` (or server-side `xml_escape`). Never inject raw.
- **Path safety:** never add a route that opens a file outside `public/`; the
  server's `_safe_path` guard must keep `../` and absolute paths blocked.
